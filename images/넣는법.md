# 🖼 사진 넣는 법 (journey.html용)

이 `images` 폴더에 아래 이름 그대로 파일을 넣고 → journey.html을 **새로고침(Ctrl+Shift+R)** 하면 자동 교체됩니다.
파일이 없으면 임시 그림이 그대로 유지돼요. 한 개씩 넣어봐도 됩니다.

## 넣을 파일 (이름 정확히)

| 파일명 | 역할 | 형식 | 추천 비율 |
|---|---|---|---|
| `sky.jpg` | 하늘/뒷배경 (눈 오는 하늘 등) | JPG/PNG | 가로로 긴 ~2:1 |
| `castle.png` | 성·건물 실루엣 | **PNG (배경 투명)** | 가로로 긴 |
| `fore.png` | 맨 앞 풍경 (눈언덕, 나무 등) | **PNG (배경 투명)** | 가로로 긴 |
| `window.png` | 창문 프레임 | **PNG (★가운데 뚫린 투명★)** | 세로로 긴 |
| `land.jpg` | 창문 너머 풍경 (노을·산 등) | JPG/PNG | 가로로 긴 ~2:1 |

## 핵심 포인트
- **`castle.png` / `fore.png` / `window.png` 는 배경이 투명한 PNG**여야 뒤 레이어가 비쳐요.
- **`window.png` 는 가운데(유리 부분)가 투명**해야 창문 너머 풍경이 보입니다. (돌 테두리만 남기고 가운데 뚫기)
- `sky.jpg`, `land.jpg` 는 그냥 꽉 찬 사진이면 됩니다.

## 사진 어디서 구하나?
1. **AI 생성** (중세 판타지 분위기엔 이게 최고)
   - Midjourney / DALL·E / 마이크로소프트 디자이너 등에 프롬프트:
     - 하늘: *"snowy medieval sky with soft sun rays, cinematic, wide"*
     - 성: *"medieval castle silhouette, isolated on transparent background"*
     - 풍경: *"warm sunset mountain landscape, wide cinematic"*
     - 창문: *"gothic stone window frame, front view, isolated"*
2. **무료 스톡**: Unsplash, Pexels (medieval / snow / mountain 검색)

## 투명 배경(누끼) 만들기 (무료)
- **remove.bg** — 사진 올리면 배경 자동 제거 → PNG 다운
- **Photopea** (photopea.com) — 무료 웹 포토샵. 창문 가운데 뚫기, 누끼 다 됨
