# AURA

스크롤에 따라 카메라가 전진하는 3D 웹 데모. Three.js로 만들었다.

프리랜서 프로필에 걸 쇼케이스용으로 시작했다. 인스타 릴스에서 본,
여러 이미지를 깊이별로 이어붙여 2.5D처럼 움직이는 효과를 웹에서 재현해보려던 것이다.

## 파일

| 파일 | 내용 |
|---|---|
| `journey.html` | 본 방향. 눈 내리는 새벽 성 → 창문 등장 → 창문을 통과해 따뜻한 풍경으로 |
| `index.html` | 실험 1. 발광하는 3D 오브 |
| `depth-parallax.html` | 실험 2. 사진 한 장을 깊이맵으로 입체화 |
| `tile-grid.html` | 실험 3. 3D 타일 그리드 |

실험 1~3은 방향이 아니라서 접었지만 아이디어 재료로 남겨뒀다.

## journey.html 구성

깊이가 다른 plane 여러 장을 쌓고, 스크롤 값으로 카메라를 전진·팬시킨다.
눈 파티클과 갓레이, 마우스 움직임에 따른 패럴랙스가 얹혀 있다.

이미지는 `images/` 폴더에서 파일명으로 읽는다 (`sky.jpg`, `castle.png`,
`fore.png`, `window.png`, `land.jpg`). 파일이 없으면 임시 도형으로 대체되므로
빈 상태로도 모션은 확인할 수 있다. 자세한 규격은 `images/넣는법.md`에 있다.

## 실행

`journey.html`을 브라우저로 열면 된다. 라이브러리와 폰트를 CDN에서 받으므로
인터넷 연결이 필요하다.

## 상태

모션은 완성했고 이미지를 못 채워서 멈춰 있다.
